## Sprint 1: Feed de Publicaciones Comunitarias

| ID | Historia de usuario | Prioridad |
| :--- | :--- | :---: |
| HU-S1-01 | Como usuario, quiero consultar un feed social comunitario que reúna momentos cotidianos, relatos de reencuentro, consejos de cuidado animal y publicaciones de búsqueda de pareja / apareamiento responsable. | Alta |
| HU-S1-02 | Como usuario, quiero crear diferentes tipos de publicaciones en el feed (momentos libres, búsqueda de apareamiento con datos de raza/sexo, consejos útiles, historias de reencuentro o alertas rápidas) adjuntando fotos desde cámara/galería y completando sus datos contextuales. | Alta |

| HU-S1-05 | Como usuario, quiero pulsar sobre cualquier publicación o tarjeta para visualizar la ficha de detalle completa de la mascota o contenido (fotos ampliadas, atributos, señas particulares, ubicación y opciones de contacto). | Alta |
| HU-S1-06 | Como usuario, quiero guardar publicaciones o reportes en mi lista de favoritos / guardados para acceder a ellos rápidamente en cualquier momento. | Media |

## Sprint 2: Feed de Reportes y Visualización de Zona en Mapa

| ID | Historia de usuario | Prioridad |
| :--- | :--- | :---: |
| HU-S2-01 | Como usuario, quiero ver un feed dedicado exclusivamente a reportes de mascotas perdidas y encontradas con tarjetas visuales priorizadas y badges de estado. | Alta |
| HU-S2-02 | Como usuario, quiero pulsar en cada reporte una opción de "Ver zona en mapa" para visualizar en un mapa contextual el barrio o zona donde se extravió o fue vista. | Alta |
| HU-S2-03 | Como usuario, quiero publicar una alerta de mascota perdida o un reporte de mascota encontrada (con foto, especie, raza, características y fecha) para difundir la situación en la comunidad y facilitar su localización. | Alta |
| HU-S2-04 | Como usuario al crear un reporte, quiero marcar un lugar en el mapa interactivo o utilizar mi ubicación actual por GPS para indicar con precisión la zona donde se perdió o fue vista la mascota. | Alta |
| HU-S2-05 | Como usuario autor de un reporte, quiero marcar mi reporte como "Caso resuelto" indicando el motivo de cierre (reencuentro con su familia, adopción / hogar definitivo, o fallecimiento) para mantener actualizada a la comunidad y finalizar la búsqueda activa. | Alta |
| HU-S2-06 | Como usuario, quiero filtrar los reportes listados en el feed según una ciudad o localidad para consultar únicamente las alertas de mascotas de mi zona geográfica de interés. | Media |

## Sprint 3: Cámara para Análisis con Inteligencia Artificial

| ID | Título | Historia de usuario | Prioridad |
| :--- | :--- | :--- | :---: |
| HU-S3-01 | Acceso al escáner de animales | Como usuario, quiero acceder al escáner de animales desde el botón central de la barra de navegación para iniciar la identificación de una mascota. | Alta |
| HU-S3-02 | Identificación de características mediante IA | Como usuario, quiero tomar una foto de un animal o seleccionar una imagen de mi galería para que la IA identifique sus características físicas, como especie, raza aparente, colores y señas particulares. | Alta |
| HU-S3-03 | Búsqueda automática de coincidencias | Como usuario, quiero que la IA compare las características del animal analizado con los reportes de mascotas perdidas y encontradas en Yago para identificar posibles coincidencias. | Alta |
| HU-S3-04 | Visualización de posibles coincidencias | Como usuario, quiero visualizar los reportes coincidentes con sus fotografías y porcentajes de similitud para evaluar si corresponden al animal que estoy buscando o encontré. | Alta |
| HU-S3-05 | Contacto con el responsable del reporte | Como usuario, quiero iniciar una conversación con el responsable de un reporte coincidente para comunicarme sobre la posible identificación de una mascota. | Alta |
| HU-S3-06 | Creación de reporte a partir del análisis | Como usuario, quiero crear un reporte de mascota encontrada cuando no se detecten coincidencias, reutilizando la fotografía analizada para agilizar el proceso. | Alta |
