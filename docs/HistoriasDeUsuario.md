# Historias de Usuario — Yago

## Sprint 1: Feed de Publicaciones Comunitarias

| ID | Historia de usuario | Prioridad |
| :--- | :--- | :---: |\
| HU-S1-01 | Como usuario, quiero consultar un feed social comunitario que reúna momentos cotidianos, relatos de reencuentro, consejos de cuidado animal y publicaciones de búsqueda de pareja / apareamiento responsable. | Alta |
| HU-S1-02 | Como usuario, quiero crear diferentes tipos de publicaciones en el feed (momentos libres, búsqueda de apareamiento con datos de raza/sexo, consejos útiles, historias de reencuentro o alertas rápidas) adjuntando fotos desde cámara/galería y completando sus datos contextuales. | Alta |
| HU-S1-03 | Como usuario, quiero reaccionar con "me gusta" a las publicaciones comunitarias para expresar apoyo e interactuar con el contenido. | Media |
| HU-S1-04 | Como usuario, quiero filtrar las publicaciones del feed por tipo de contenido (Todos, Perdidas, Encontradas, Reunidas, Apareamiento, Comunidad) para visualizar únicamente los temas que me interesan. | Alta |
| HU-S1-05 | Como usuario, quiero pulsar sobre cualquier publicación o tarjeta para visualizar la ficha de detalle completa de la mascota o contenido (fotos ampliadas, atributos, señas particulares, ubicación y opciones de contacto). | Alta |
| HU-S1-06 | Como usuario, quiero guardar publicaciones o reportes en mi lista de favoritos / guardados para acceder a ellos rápidamente en cualquier momento. | Media |

## Sprint 2: Feed de Reportes y Visualización de Zona en Mapa

| ID | Historia de usuario | Prioridad |
| :--- | :--- | :---: |
| HU-S2-01 | Como usuario, quiero ver un feed dedicado exclusivamente a reportes de mascotas perdidas y encontradas con tarjetas visuales priorizadas y badges de estado. | Alta |
| HU-S2-02 | Como usuario, quiero pulsar en cada reporte una opción de "Ver zona en mapa" para visualizar en un mapa contextual el barrio o zona donde se extravió o fue vista. | Alta |
| HU-S2-03 | Como usuario, quiero publicar una alerta de mascota perdida con foto, especie, raza, características, fecha y zona de extravío para iniciar su búsqueda activa. | Alta |
| HU-S2-04 | Como usuario, quiero publicar un reporte de mascota encontrada cuando retengo o veo a un animal en la vía pública para que su familia pueda ubicarlo. | Alta |
| HU-S2-05 | Como usuario autor de un reporte, quiero marcar mi reporte como "Caso resuelto" indicando el motivo de cierre (reencuentro con su familia, adopción / hogar definitivo, o fallecimiento) para mantener actualizada a la comunidad y finalizar la búsqueda activa. | Alta |
| HU-S2-06 | Como usuario, quiero filtrar los reportes activos exclusivamente entre mascotas perdidas y encontradas (sin mostrar casos resueltos) para enfocarme únicamente en las alertas vigentes que requieren ayuda comunitaria. | Media |

## Sprint 3: Cámara para Análisis con Inteligencia Artificial

| ID | Historia de usuario | Prioridad |
| :--- | :--- | :---: |
| HU-S3-01 | Como usuario, quiero acceder a la cámara analizadora desde el botón central de la barra de navegación para identificar a un animal que veo en la calle o cotejar a mi mascota perdida. | Alta |
| HU-S3-02 | Como usuario, quiero capturar una foto con la cámara (o cargar una imagen de la galería) para que el modelo de IA extraiga sus rasgos físicos (especie, raza aparente, colores y señas particulares). | Alta |
| HU-S3-03 | Como usuario, quiero que la IA busque y compare automáticamente la foto analizada contra la base de datos activa de Yago, abarcando tanto mascotas reportadas como perdidas como mascotas encontradas por otros usuarios. | Alta |
| HU-S3-04 | Como usuario, quiero visualizar el resultado de la búsqueda con el porcentaje de similitud visual y las fotos comparativas ante posibles coincidencias (perdidas o encontradas). | Alta |
| HU-S3-05 | Como usuario, quiero abrir un chat directo con la persona responsable del reporte coincidente (dueño o reportante de hallazgo) desde el resultado del análisis de IA para avisarle al instante que su mascota fue avistada. | Alta |
| HU-S3-06 | Como usuario, quiero que la app me permita generar un nuevo reporte de mascota encontrada si la IA no detecta coincidencias, reutilizando la foto tomada para ahorrar tiempo. | Alta |
