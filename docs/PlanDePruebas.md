# 📋 Plan de Pruebas – Yago (Sprints 1 y 2)

| Historia de Usuario | Criterio de Aceptación (Given–When–Then) | Tipo de Prueba | Responsable | Estado |
| :--- | :--- | :---: | :---: | :---: |
| Como usuario, quiero registrarme o iniciar sesión para guardar mis publicaciones y reportes. | **Given** que soy un nuevo usuario **When** me registro con datos válidos **Then** se crea mi cuenta y puedo ingresar a la app. | Funcional | QA / Tester | Pendiente |
| Como usuario, quiero mantener mi sesión iniciada para no tener que ingresar mis datos cada vez. | **Given** que ya inicié sesión **When** cierro y vuelvo a abrir la app **Then** ingreso directo al feed sin tener que volver a iniciar sesión. | Funcional | QA / Tester | Pendiente |
| Como usuario, quiero consultar un feed comunitario para enterarme de novedades, historias y consejos sobre mascotas. | **Given** que abro la app **When** ingreso al feed **Then** veo las publicaciones con sus fotos, autores y descripciones. | Funcional | QA / Tester | Pendiente |
| Como usuario, quiero crear publicaciones en el feed para compartir fotos y experiencias con la comunidad. | **Given** que elijo crear una publicación **When** subo una foto, elijo la categoría y escribo un texto **Then** se publica y aparece en el feed comunitario. | Funcional / Campo | QA / Tester | Pendiente |
| Como sistema, debo validar los datos obligatorios al crear una publicación para evitar contenidos incompletos. | **Given** que intento crear una publicación **When** falta la foto o la descripción **Then** el sistema me avisa qué datos faltan y no permite publicar. | Funcional / Usabilidad | QA + Diseñador UX | Pendiente |
| Como usuario, quiero reaccionar con me gusta a las publicaciones para apoyar a la comunidad. | **Given** que veo una publicación **When** toco el corazón **Then** se suma un me gusta y el corazón cambia de color. | Funcional | QA / Tester | Pendiente |
| Como usuario, quiero filtrar el feed por categorías para ver solo el contenido que me interesa. | **Given** que estoy en el feed **When** elijo una categoría (como consejos o apareamiento) **Then** solo veo las publicaciones de esa categoría. | Funcional / Usabilidad | QA + Diseñador UX | Pendiente |
| Como usuario, quiero abrir una publicación para ver la información completa de la mascota y contactar al autor. | **Given** que veo una publicación **When** la toco **Then** se abre la ficha con la foto grande, datos de la mascota y opción de contacto. | Funcional / Usabilidad | QA / Tester | Pendiente |
| Como usuario, quiero guardar reportes/publicaciones para encontrarlas rápido más adelante. | **Given** que veo una publicación útil **When** toco el botón de guardar **Then** queda guardada en mi lista de favoritos. | Funcional | QA / Tester | Pendiente |
| Como usuario, quiero ver un feed de mascotas perdidas y encontradas para ayudar en la búsqueda. | **Given** que entro a reportes **When** carga la pantalla **Then** veo las tarjetas de animales perdidos y encontrados con sus estados diferenciados. | Funcional | QA / Tester | Pendiente |
| Como usuario, quiero ver la zona en un mapa en cada reporte para saber dónde se vio a la mascota. | **Given** que veo un reporte **When** toco "Ver zona en mapa" **Then** se abre un mapa centrado en la zona con un pin de ubicación. | Funcional / Usabilidad | QA + Diseñador UX | Pendiente |
| Como usuario, quiero publicar una alerta de mascota perdida o encontrada para pedir ayuda a la comunidad. | **Given** que completo los datos de la mascota **When** publico el reporte con su foto, especie y fecha **Then** la alerta queda visible en el feed de reportes. | Funcional / Campo | QA / Tester | Pendiente |
| Como usuario, quiero reportar cualquier tipo de animal sin que me obliguen a indicar rasgos que no corresponden. | **Given** que reporto un animal no convencional (como ave o tortuga) **When** no conozco su edad exacta **Then** el sistema me permite indicar que no la sé y publicar normalmente. | Funcional / Usabilidad | QA + Diseñador UX | Pendiente |
| Como usuario, quiero usar mi GPS al reportar para indicar rápido el lugar exacto donde ocurrió. | **Given** que el GPS está activo **When** toco usar mi ubicación actual **Then** el mapa marca el punto donde estoy y completa la zona. | Campo (GPS) | QA + Usuario beta | Pendiente |
| Como usuario, quiero marcar la ubicación en el mapa manualmente si el hecho ocurrió en otro lugar. | **Given** que abro el mapa en el reporte **When** toco o muevo el pin a la calle correcta **Then** la ubicación del reporte se guarda en ese punto. | Funcional / Campo | QA / Tester | Pendiente |
| Como autor de un reporte, quiero marcarlo como caso resuelto cuando la mascota vuelva a su hogar. | **Given** que soy el dueño del reporte **When** lo marco como resuelto y elijo el motivo **Then** el reporte cambia a resuelto y finaliza la búsqueda. | Funcional | QA / Tester | Pendiente |
| Como sistema, debo evitar que un usuario cierre un reporte ajeno para proteger la información. | **Given** que veo el reporte de otra persona **When** reviso las acciones disponibles **Then** no puedo ver ni usar la opción de cerrar el caso. | Funcional / Seguridad | QA / Backend Dev | Pendiente |
| Como usuario, quiero filtrar reportes por localidad para ver solo las alertas de mi ciudad. | **Given** que estoy en el feed de reportes **When** elijo mi ciudad en el filtro **Then** solo veo los reportes correspondientes a esa localidad. | Funcional / Usabilidad | QA + Diseñador UX | Pendiente |
